
# ALS — AppOk Licensing System

## 🔐 Sobre o projeto

O ALS (AppOk Licensing System) é um sistema de gerenciamento e controle de licenças de software, desenvolvido para administrar a ativação e a utilização do aplicativo Android AppOk.

O projeto integra a gestão de licenciamento ao desenvolvimento de software, com foco em organização, controle de acesso e evolução da solução.

## 🚀 Funcionalidades

- Gerenciamento de licenças de utilização.
- Identificação e controle de planos de licenciamento.
- Suporte aos planos BASIC, PROFESSIONAL e PREMIUM.
- Controle de período de avaliação (trial) de 15 dias.
- Ativação de licenças por número serial.
- Integração com o aplicativo Android AppOk.

## 🏗️ Arquitetura e integração

O ALS atua como componente de gerenciamento de licenças do ecossistema AppOk, permitindo organizar os diferentes níveis de acesso ao aplicativo.

O projeto foi concebido para atender às necessidades de licenciamento do AppOk, com possibilidade de evolução e adaptação para outras soluções de software.

## 🎯 Objetivos técnicos

- Aplicar conceitos de Engenharia de Software na construção de soluções integradas.
- Estruturar regras de negócio para licenciamento e ativação.
- Desenvolver mecanismos de gerenciamento do ciclo de vida das licenças.
- Evoluir a integração entre aplicações e sistemas de controle.

Este repositório é destinado à apresentação técnica e à documentação pública do projeto.
